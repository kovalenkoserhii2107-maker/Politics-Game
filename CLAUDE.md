# Правила работы над проектом

## Git

**Коммитить и пушить сразу, без отдельного разрешения.** Как только изменение
доведено до рабочего состояния и проверено — сразу `git commit` и
`git push -u origin <ветка>`. Не копить изменения в рабочей копии и не
спрашивать «отправлять ли». Разрешение выдано владельцем репозитория.

Исключения, где всё-таки надо спросить:
- пуш в `main` или в любую ветку, кроме рабочей;
- создание pull request;
- операции, переписывающие историю (`rebase`, `amend`, force-push) в уже
  отправленных коммитах.

Сообщения коммитов — на русском, по существу: что изменилось и почему.

## Данные карты

`js/data/*.js` генерируются, вручную их не править. После любой правки
`tools/build_map.js` или справочников в `tools/data/` — перегенерировать:

```bash
cd tools && node build_map.js
```

Генератор детерминирован, занимает ~40 с. Результат коммитить вместе с
изменениями генератора.

## Проверка изменений

В проекте нет тестов и сборки — это статическая страница. Перед коммитом
изменений в движке прогнать игру в браузере (Playwright, Chromium лежит в
`/opt/pw-browsers/chromium`): старт за несколько стран, клик по области,
марш, атака, отмена приказа, конец хода. Смотреть на ошибки консоли — их
должно быть ноль.

Отдельно проверять мобильный вид с `deviceScaleFactor: 3`: баги растеризации
SVG на iOS не воспроизводятся в обычном десктопном окне.
