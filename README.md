# Politics-Game

Пошаговая стратегия на карте мира. Открывается как статическая страница —
`index.html`, без сборки и без сервера.

## Устройство

```
index.html          разметка и стили интерфейса
js/                 движок игры
  UnitsDB.js        рода войск
  GameData.js       модель мира: страны, области, войны, приказы, бой, экономика,
                    исследования, сохранение (правила — в объекте RULES)
  AI.js             поведение компьютерных стран (объект AI_RULES)
  MapEngine.js      отрисовка карты, камера, подписи, маркеры
  UIManager.js      панели, модальные окна, отчёт хода, журнал приказов
  GameLoop.js       смена хода и сохранение в localStorage
  main.js           контроллер и стартовый экран
  data/             СГЕНЕРИРОВАННЫЕ данные — вручную не править
tools/              офлайн-генератор данных
manifest.webmanifest, icons/   установка на телефон как приложение (PWA)
```

## Игра

Один ход — неделя. Старт 1 января 2024 г. в мирном мире или в «Сценарии 2024»
(с первого хода идёт война России и Украины).

- **Экономика.** Доход — налоги с населения и промышленности, расход —
  содержание войск. Налог настраивается в «Правительстве». При долгах армия
  дезертирует, при высоком налоге падает лояльность.
- **Армия.** Пять родов войск с взаимными контрами. Набор ограничен
  промышленной мощностью области. Войска можно перебрасывать, объединять
  атаки из нескольких областей и распускать, чтобы снизить расходы.
- **Бой.** Обороняющийся получает бонус; столица — дополнительный. Если
  область не удержана, уцелевшие отступают в соседнюю свою. Пустую область
  защищает ополчение. Разведка показывает армию врага.
- **Дипломатия.** Атаковать можно только страну, с которой идёт война.
  Объявление войны и мир стоят влияния; после мира — перемирие на 10 ходов.
  Компьютерные страны сами воюют между собой, нападают и предлагают мир.
- **Исследования** повышают силу родов войск и скорость марша.
- **Развитие.** Промышленность, агрокомплекс и энергетика приносят доход.
  Строительство оплачивается сразу и завершается через 2–3 хода. Политический
  курс меняет бюджет и лояльность; промышленность также повышает мощность набора.
- **Кампания.** Первые шаги ведут от бюджета к первому завоеванию. Победа —
  контроль всех 689 областей суверенных стран. Логистика 3 открывает экспедиции
  к удалённым целям: $500 тыс. + $25 тыс. за подразделение и 5 влияния.
- **Сохранение** автоматическое после действий и каждого хода. Формат v3
  сохраняет проекты, политику и ожидающие решения. Миграции с v2 пока нет.
  Несовместимые сохранения не удаляются автоматически: новая кампания заменяет
  их после подтверждения.

## Карта

Области получаются нарезкой каждой страны сеткой квадратов, обрезанной по
государственной границе. Число областей зависит от площади страны:

    N = clamp(round(20 * (площадь / площадь_России) ^ 0.4145), 1, 20)

Опорные точки правила: Россия — 20 областей, Украина — 5, Молдова — 2, малые
страны — 1. Куски мельче 30% средней площади области присоединяются к соседу
с самой длинной общей границей (при отсутствии общей границы — к ближайшему).

Названия областей берутся от крупнейшего города внутри области; если городов
нет, область получает название по стороне света (сектор 3x3 внутри страны,
каждой области — свой сектор, поэтому названия не повторяются).

Соседство считается по геометрии: общая сухопутная граница плюс морские
переправы короче 120 км. Дополнительно гарантируется, что граф областей
каждой страны связный и у каждой области есть хотя бы один сосед.

## Источники данных

| Что | Откуда |
|---|---|
| Геометрия стран | Natural Earth 1:50m (`world-atlas`) |
| Названия стран, площади | `world-countries` (русские переводы) |
| Население стран | ООН, World Population Prospects 2024 (`tools/data/population_2024.json`) |
| Города: координаты и население | `all-the-cities` |
| Города: русские названия | `tools/data/cities_legacy.js` + `tools/data/cities_ru.json` |

Карта рисуется в проекции Web Mercator в системе координат viewBox 1200x800.
Константы проекции — в `tools/lib/geo.js`.

## Пересборка данных

```bash
cd tools
npm install
node build_map.js      # ~40 c, перезаписывает js/data/*.js
```

Генератор детерминирован: одинаковый вход даёт одинаковый выход.
